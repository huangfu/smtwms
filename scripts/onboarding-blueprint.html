新建工厂导入前置条件（4 大准入维度）

FACTORY READINESS PREREQUISITES

WMS 是「三分软件、七分管理与数据」。新建工厂在系统正式启动部署前，必须先完成以下四个维度的基础设施与管理准入评审，避免系统沦为事后补录台账的工具。

1. 组织与岗位权责就绪（人）
  • 设立专职项目负责人（通常为仓储经理或供应链总监），具备跨 PMC/生产/品质协调拍板权。
  • 配齐核心操作岗位并分配独立系统账号（禁止多人共用公用账号）：仓库主管、IQC/MSD 专员、收发料仓管员、PMC 计划员、ME 工程（BOM 维护）、IT 管理员。
  • 完成基础扫码与贴标作业实操考核，全员理解「实物移动必伴随系统扫码」。
2. 物理仓区与防静电/防潮达标（场）
  • 电子料主仓（EPA 防静电区）：恒温 20–26°C、相对湿度 30–60% RH，防静电地板与接地达标。
  • MSD 防潮专仓：配置 RH < 5% 低湿氮气柜/电子防潮柜及 40°C/125°C 精密工业烘箱。
  • 五区硬隔离：收货/IQC 待检区、良品主库区、MSD 防潮区、产线线边暂存区、MRB 不良/报废隔离区。
  • 储位物理编码落地：所有货架/料车完成物理贴码（如 A-01-01 排-架-层），与系统库位 1:1 映射。
3. 网络与 IT 部署环境就绪（网/算）
  • 全库区无死角覆盖：收发料操作台布设千兆有线网口；库区与 SMT 车间部署工业级 Wi-Fi 6（无缝漫游，避免手持终端断连）。
  • 数据库与服务端部署：生产环境推荐局域网独立服务器部署 React 前端 + .NET 10 + FreeSql 后端，连接企业 MSSQL (SQL Server) 或 PostgreSQL；启用每日全备 + 事务日志备份。
  • 打印链路通畅：网口 Zebra 打印机分配固定静态 IP 且开放 TCP 9100 端口；USB 打印机工位 PC 预装 Zebra Browser Print 服务。
4. 不可逾越的 4 条管理红线（制）
  • 红线一：一盘一码——无系统唯一 Reel UID 标签的料盘严禁上架、严禁发往 SMT 产线。
  • 红线二：见单发料——严禁任何口头借料、先拿料后补单，特殊急料走「补料」流程并记录工单与机台。
  • 红线三：敬畏防呆——严禁人为跳过 FIFO 先进先出拦截，严禁将系统锁定「需烘烤」的 MSD 料盘直接上线。
  • 红线四：产权隔离——客供料与专属定制料严禁跨客户挪用，所有发料必须核验工单归属客户。

本系统 3 项关键主数据建模规范（新厂务必遵循）

1. 物料复合主键与 MPN 规则

同一原厂料号（如 STM32F407VET6）可能同时存在「自购公用」「A 客户客供」「B 客户专属」库存。本系统采用 SKU + 产权类型 + 归属编码 作为唯一主键；新建料号默认自动沿用 MPN（减少编码维护成本），也可按工厂内部规则自由覆盖。

2. 非客供料的客户归属绑定

即使物料产权为「自购」或「VMI 寄售」，若该料专为某大客户备货，可在物料清单中勾选对应业务客户。波次发料与产线补料时，系统优先消耗匹配客户库存，并阻断跨客户误发，避免交付违约。

3. 单表管理主料 / 特料 / 代用料

放弃繁琐的多表替代关系维护，在单一 BOM 表中通过 itemRole（主料 MAIN / 特料 SPECIAL_MAIN / 代用料 SUBSTITUTE）与 substituteFor 字段直观表达替代优先级，既方便工程核对，又保障齐套计算精准。

MSL 等级 车间暴露寿命 (≤30°C/60%RH) 系统自动管控行为 推荐存放库区 超时后标准处置
Level 1 无限制 不启动拆封计时，正常 FIFO 发料 电子料主库区 (WH-SMT) 无需烘烤
Level 2 1 年（8,760 小时） 发料拆封记录开封时间，低风险预警 电子料主库区 / 密封袋 超时提示复检或干燥
Level 2a 4 周（672 小时） 拆封自动倒计时，剩余 <20% 看板预警 防潮柜 (RH<10%) 系统锁盘，烘烤复位
Level 3 168 小时（7 天） SMT 最常见 IC 等级；拆封即计时，超时硬锁定 低湿氮气柜 (RH<5%) 125°C 烘烤 + 系统 MSD_BAKE
Level 4 72 小时（3 天） 高敏 QFN/BGA；临期红色高亮，退库必须回防潮柜 低湿氮气柜 (RH<5%) 125°C 烘烤 + 抽真空重封
Level 5 / 5a 48 小时 / 24 小时 极高敏器件；建议单班按需现拆现贴 超低湿氮气柜 + 专人盯控 严格按原厂曲线烘烤复位

SMT 车间管理模式与 6 大作业闭环设计

WORKSHOP OPERATING MODEL & SOP

新建工厂应一步到位建立「计划驱动 + 条码防呆 + 产权隔离 + 湿敏闭环 + 数据追责」的精益电子仓管理模式，彻底告别手工 Excel 台账与「凭老师傅记忆找料」。以下六大管理机制与系统功能逐一咬合：

机制一：ASN 预入库与「一盘一码」赋码上架闭环

  1. 预约建单：采购下单后，在系统手工创建或通过 CSV 一键导入 ASN 预约入库单（含 PO 号、供应商、预计数量、目标库位）。
  2. 到货扫码解析：IQC 检验合格后，仓管员用二维扫码枪扫描原厂料盘条码；系统自动匹配该供应商的 条码解析规则，瞬间提取 MPN、Lot、4 位 DateCode 与数量。
  3. 赋唯一 UID 与 ZPL 打标：核对包装 SPQ 无误后提交入库，系统自动生成全局唯一 Reel UID，并直推 Zebra 打印机输出含二维复合码、产权标识、MSL 等级与库位信息的标准标签。
  4. 按推荐库位上架：仓管员贴标后放入对应防静电架或 MSD 防潮柜；ASN 明细自动累计实收进度，杜绝超收、错收。

机制二：客供 / VMI / 专属物料「产权与客户隔离」管控

物理 + 账务双重隔离

通过物料复合主键 SKU + 产权 + 归属编码，系统在账面上天然隔离同一料号的自购料与各家客户客供料；实体货架建议用不同颜色标识牌划分「公用区」与「大客户专料区」。

系统硬拦截跨客户混发

当新建工单关联特定客户后，波次发料与产线补料会自动优先锁定该客户的客供/专属料盘，允许补充使用公用自购料，但严禁将 B 客户客供料或专属料发给 A 客户工单，从机制上消灭赔款风险。

机制三：多工单波次齐套与「强制 FIFO 先进先出」防呆

  1. 单表 BOM 精准齐套：PMC 排产建立工单时直接关联单表 BOM（自动识别主料、特料及代用料）。合并多张同线或同班次工单生成发料波次 (Wave)，系统秒级核算可用库存并输出精确的缺料清单，避免上线后才发现停线待料。
  2. DateCode 升序自动锁盘：创建波次时，系统自动跳过「MSD 需烘烤」与状态异常料盘，严格按 4 位 DateCode 升序 → 入库时间升序分配最早批次料盘。
  3. 拣料扫码 FIFO 硬防呆：仓管员拣货扫码确认时，若拿取了较新批次的料盘而同料号尚有更老批次未发出，系统立即弹窗硬拦截报错，强制纠正拿料顺序，实现 0 人工干预的真 FIFO。
管理模式核心变革：传统工厂靠「仓管员自觉看日期」执行 FIFO，准确率通常低于 75%；导入本系统后，将 FIFO、客户防混发、MSD 烘烤检查全部下沉为扫码瞬间的系统硬校验，新员工培训 1 天即可达到资深仓管员的防错水准。
第四章：SMT 车间管理模式与作业闭环设计（续） 6 大核心管控机制（4–6）

机制四：MSD 湿敏元件全生命周期防潮烘烤闭环

针对 Level 2a–5a 湿敏 IC（如 MCU、BGA、QFN），工厂须严格执行「入柜密封 → 发料启表 → 超时硬锁 → 烘烤复位」四步闭环：

  • 入库密封态 (SEALED)：新到真空防潮包装料盘入库后存于氮气柜，不扣减车间寿命。
  • 发料自动开封计时 (OPENED)：波次发料至 SMT 产线时，系统自动记录拆封时间戳，并在仓储总览看板实时计算剩余暴露小时数。
  • 超时强制锁定 (BAKING_REQUIRED)：一旦暴露超限，系统自动将料盘置为红色锁定态，禁止一切发料、补料与波次分配。
  • 烘烤登记与复位 (MSD_BAKE)：IQC/MSD 专员按标准曲线（如 125°C 烘烤规定时长）烘烤完毕后，在系统记录烤箱参数与操作人完成复位解锁，全流程可审计。

机制六：ABC 分类循环盘点与全链路正反向追溯

  • A 类高价值/关键 IC（每周盘点）：按库区在系统创建循环盘点任务，实盘录入后系统自动算盈亏并生成调账流水。
  • B 类常规贴片件（每月盘点）：结合月底关账抽盘，差异率超过 0.2% 触发复盘。
  • C 类低值通用阻容（每季盘点）：重点核对料盘数与整盘 SPQ 一致性。

新建工厂导入 SMT-WMS 最常见的 5 大避坑指南

避坑 1：为了赶进度，跳过「主数据标准化」直接上线收发料

后果：同一物料出现多种命名、MSL 全部默认填 Level 1、包装 SPQ 缺失，导致湿敏报警全部失灵、BOM 齐套算错。
对策：严格卡住第 4 周数据冻结关口，由 ME 与仓库共同签字确认主数据清单后再开跑试运行。

避坑 2：贪图便宜采购 203 DPI 低精度打印机或普通热敏纸

后果：50×30mm SMT 小标签上的高密度二维复合码边缘发虚，扫码枪反复扫不出；热敏纸过烘箱后发黑失效。
对策：一步到位选用 300 DPI 热转印 Zebra 打印机 + 混合基/树脂碳带 + 哑银/防静电铜版纸。

避坑 3：发料管得严，但「产线退料」不复点、不换标

后果：产线肉眼估算退料数量，1 个月后系统账面与料盘真实余量偏差超 15%，直接拖垮波次齐套准确性。
对策：立下铁律——退料必过 X-Ray/光学点数机，按实测数在系统执行退料/拆子盘并立即重打新标签覆盖旧标。

避坑 4：允许「急单口头先拿料，明天再补账」

后果：一旦开了先例，仓库迅速退化为「事后补录」，FIFO、MSD 计时与实时库存彻底失去可信度。
对策：急料统一走系统「产线补料」快捷入口（10 秒扫码完成），管理层严查任何无单离线领料行为。

避坑 5：忽视「非客供料」的客户专料归属与备份容灾

后果：A 客户专属自购长交期芯片被 B 客户急单挪用导致停线；或单机硬盘损坏丢失全年追溯数据。
对策：充分利用本系统「物料业务客户绑定」防混发功能；MSSQL/PostgreSQL 务必配置每日自动异地备份与演练。
