# Zebra ZPL 可视化标签设计与打印规范

## 1. 适用场景
- 调整标签模板尺寸（预设或自定义宽高 mm）、打印精度（203 / 300 / 600 / 自定义 DPI）。
- 新增或编辑标签画布元素（主条码、附加条码 CODE128/CODE39/QR/DataMatrix、自定义文本、边框/分隔线）。
- 调整条码对应文字（HRI）的上下位置、偏移、字体、加粗、反白与对齐，或校准打印机全局 X/Y 偏移。

---

## 2. 核心技术规范（MUST）

### 2.1 物理毫米到点阵（mm → dots）统一换算
- 所有画布坐标与尺寸在数据模型中统一以 **物理毫米 (`mm`)** 存储，严禁写死 203 DPI 像素值。
- 编译 ZPL 时通过 `mmToDots(mm, dpi)` 动态换算（`Math.round((mm * dpi) / 25.4)`），保证同一模板切换 `203 / 300 / 600 DPI` 后物理排版尺寸一致。
- 标签宽度 `^PW` 与长度 `^LL` 基于当前有效纸张尺寸（支持 `CUSTOM` 自定义宽高，范围 `20~200mm`）与 DPI 动态计算。

### 2.2 整体 X / Y 偏移校准
- 支持微调全局 `offsetXMm` / `offsetYMm`（应对不同热敏打印机传感器机械偏差）：
  - 正向偏移使用 `^LH{xDots},{yDots}`；
  - 负向 X 偏移使用 `^LS{xDots}`，负向 Y 偏移使用 `^LT{yDots}`；
  - 可视化预览画布必须同步实时体现全局偏移效果，做到**所见即所得（WYSIWYG）**。

### 2.3 条码与 HRI 人眼可读文字分离控制
- 为了支持自由调整条码文字的位置（上方/下方/隐藏）、相对 X/Y 微调、字号、字体、加粗、反白（`^FR`）与对齐（`^FB`）：
  - 1D 条码指令（`^BC` / `^B3`）自身关闭内置解释行（设为 `N,N,N`）；
  - 由独立的 HRI 布局计算函数 `computeBarcodeHriBoxMm` 计算精确坐标，并在 ZPL 与画布预览中分别渲染，保证画布预览与热敏出纸位置一致。

### 2.4 ZPL 注入安全与变量插值
- 所有动态字段值（MPN、Lot、客户名、自定义文本模板）在拼入 `^FD...^FS` 前必须经过 `sanitizeZplText` 清洗，剥离/替换 `^`、`~` 及换行符，防止破坏 ZPL 指令结构。
- 保留 `VISUAL`（可视化生成）与 `CUSTOM_ZPL`（高级手写 ZPL 模板 + `{{变量}}` 插值）双模式兼容；自定义 ZPL 若未写 `^PQ` 份数指令，自动注入 `^PQ{copies},0,1,Y`。

---

## 3. 禁止的反模式（DON'T）
- ❌ **禁止画布预览用一套布局、ZPL 导出用另一套写死坐标**：必须共用同一份 `elementLayouts` 与换算函数。
- ❌ **禁止在升级模板字段时破坏旧数据反序列化**：`normalizeWmsState` 与 `normalizeElementLayouts` 必须无损兼容历史模板与数据库 JSONB 字段。
- ❌ **禁止忽略自定义元素持久性**：新增的 `CUSTOM_BC_*`、`CUSTOM_TXT_*`、`CUSTOM_BOX_*` 在保存、刷新、数据库往返映射后必须 100% 保留。
